**FocusFlow** is an aesthetic, dark-themed productivity web application designed for students, software engineers, and remote workers. Built to eliminate digital distractions, it combines the **Pomodoro Technique**, customizable **Ambient Soundscapes**, and an intuitive **Focus Task Manager** into a sleek single-page experience.

---

## ✨ Key Features

- ⏱️ **Pomodoro Timer Engine**
  - Seamlessly switch between **Focus (25m)**, **Short Break (5m)**, and **Long Break (15m)** modes.
  - Dynamic UI background glow and accent color shifts based on the active timer state.
  - Interactive visual progress ring/bar and page title counter.

- 🎧 **Ambient Soundscape Synthesizer**
  - Synthesized ambient audio (Rain, Cafe, Ocean Waves) built natively using the browser's **Web Audio API** (no external audio files required).
  - Independent volume sliders to layer multiple soundscapes simultaneously.

- 🎯 **Target Task Management**
  - Add, track, and cross off active study/work tasks.
  - Set an active target task that updates directly under the countdown timer.

- 📊 **Productivity Statistics**
  - Local tracking for **Total Sessions**, **Focus Hours**, and **Completed Tasks**.
  - Persistent storage using `LocalStorage` so your progress remains saved across sessions.

- 🌙 **Minimalist UI/UX Design**
  - Modern typography using *Plus Jakarta Sans* & *Space Grotesk*.
  - Fullscreen mode support for distraction-free study environments.

---

## 🛠️ Built With

- **HTML5 & Modern CSS3**: Custom CSS variables, Flexbox/Grid layouts, and glassmorphism UI.
- **Vanilla JavaScript (ES6+)**: Modular application state, interval timers, and local storage management.
- **Web Audio API**: Real-time audio node synthesis for smooth ambient soundscapes.
